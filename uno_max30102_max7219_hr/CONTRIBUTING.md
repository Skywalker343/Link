# Contributing

This repository is a portfolio prototype. Contributions should keep the difference between measured sensor data and generated demo data visible in both code and interface.

- Keep the local demo free of names, booking identifiers, or other personal data.
- Do not add diagnosis, behavior inference, or automated decisions based on a sensor value.
- Document new hardware, wiring, dependencies, and known measurement limits.
- Preserve upstream notices in any adapted third-party source.
- Keep the server bound to localhost unless authentication, transport security, and access controls are added and reviewed.

For code changes, describe the hardware or browser environment used and list manual verification steps in the pull request.
